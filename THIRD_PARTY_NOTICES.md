# Third-Party Notices

KoreanMapSTLmaker depends on open-source Python packages. The direct runtime
dependencies currently include GeoPandas, NumPy, pyproj, Rasterio, Shapely,
Trimesh, and Streamlit. Pytest is used for development and release checks.

Typical upstream licenses include BSD-3-Clause, MIT, and Apache-2.0. A release
publisher must preserve the license and notice files installed with every
packaged dependency and repeat the audit for the exact release environment.

This notice is informational and is not a substitute for legal review. Input
datasets and generated outputs are governed separately by their source terms.
